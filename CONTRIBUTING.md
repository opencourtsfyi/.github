# Contribution Guidelines

These guidelines apply across OpenCourts.fyi repositories.

## How to Contribute

- Open an issue for proposals, questions, or problems.
- Submit PRs for improvements; keep changes small and scoped.
- Prefer edits that reduce volunteer burden and improve clarity.

## Style

- Use clear headings and concise language.
- When changing requirements or architecture, link to an issue and consider adding/updating an ADR in `opencourts-governance`.

## Automation

Automation artifacts live under `automation/`.
If automation changes governance outcomes, include clear disclosure and auditability notes.
